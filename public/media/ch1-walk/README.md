# ch1-walk media

Drop real photos here. Nothing is required: the scene is fully procedural.

- Photo slot (polaroid beside the trophy shelf): add e.g. `childhood.jpg`, then set
  `PHOTO.src = '/media/ch1-walk/childhood.jpg'` in `src/story/scenes/ch1-walk/config.ts`.
  It is dithered to the four Game Boy greens at runtime (22x20 px, cover-fit), so any photo works; faces with good contrast dither best.
- Do not add anything that is not Risheek's own photo. Until then the slot stays a labelled placeholder.
